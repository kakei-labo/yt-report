プライバシーポリシー

「個人用 YouTube 成績ツール」（以下、このツール）は、YouTube チャンネルの持ち主が、自分のチャンネルの成績を読むためだけに使う個人用のプログラムです。持ち主以外の方の情報は扱いません。

1. 読む情報

  • 持ち主が Google のログインで許可した範囲（YouTube Analytics の読み取り・YouTube の読み取り）で、持ち主のチャンネルの成績（視聴回数・視聴時間・高評価の数・流入元・視聴者の年齢と性別の割合など、集計された数字）と、動画の情報を読みます。
  • 視聴者一人ひとりを特定できる情報は、読みません。

2. 使い方

  • 読んだ情報は、持ち主が自分の動画づくりのための分析にだけ使います。
  • 広告や販売、ほかの人への提供には使いません。

3. 保存と共有

  • 読んだ情報と、ログインの許可の合い鍵は、持ち主の手元の PC と、持ち主だけが見られる保存場所に置きます。
  • 第三者には渡しません。

4. 許可の取り消し

持ち主は、Google アカウントの「サードパーティ製のアプリとサービス」から、いつでもこのツールへの許可を取り消せます。取り消すと、このツールは情報を読めなくなります。

5. Google の API サービスの利用について

このツールが Google の API から受け取った情報の使い方は、Google API サービスのユーザーデータに関するポリシー（限定的な使用の要件を含む）に従います。

6. 変更

このポリシーを変えるときは、このページを直します。

Privacy Policy (summary in English)

  • This tool is a private program used only by the YouTube channel owner to read their own channel's aggregated analytics (read-only scopes: YouTube Analytics readonly, YouTube readonly).
  • It does not collect information that identifies individual viewers, and it does not handle anyone else's data.
  • Data is used only for the owner's own analysis, stored on the owner's computer and storage that only the owner can access, and never shared with third parties or used for advertising.
  • The owner can revoke access at any time from their Google Account's "Third-party apps & services" page.
  • Use of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.
