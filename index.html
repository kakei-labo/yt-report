個人用 YouTube 成績ツール

このツールは、YouTube チャンネルの持ち主が、自分のチャンネルの成績（視聴回数・視聴時間など）を自分で読むためだけに使う、個人用のプログラムです。一般の方に向けたサービスではなく、持ち主以外は使えません。

していること

  • Google のログインで持ち主が許可したうえで、YouTube Analytics API と YouTube Data API から、持ち主のチャンネルの成績を読むだけです（動画やチャンネルの設定を変えることはありません）。
  • 読んだ数字は、持ち主の手元の PC と、持ち主だけが見られる保存場所に置き、分析に使います。
